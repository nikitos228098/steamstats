# SteamStats — Полная статистика игрока в Steam 🎮

Современное веб-приложение для детального анализа и визуализации профилей игроков Steam.

![SteamStats Preview](https://community.cloudflare.steamstatic.com/public/shared/images/header/globalheader_logo.png)

## 🚀 Возможности сервиса

1. **Информация о профиле игрока**:
   - Аватар, никнейм, настоящее имя, страна и статус (В сети, В игре, Отошёл, Не в сети).
   - Уровень Steam, текущий опыт (XP) и прогресс-бар до следующего уровня.
   - Дата регистрации и точный возраст аккаунта (в годах и днях).
   - Проверка блокировок (VAC-бан, блокировка сообщества, трейд-бан).
   - Быстрое копирование SteamID64 и переход в официальный профиль Steam.

2. **Аналитика библиотеки и наигранных часов**:
   - Общее время в играх: в часах, днях и непрерывных месяцах.
   - Прогресс бэклога ("Куплено / Сыграно" против "Не запущено ни разу").
   - Недавняя активность (часы за последние 14 дней).
   - Оценка ориентировочной рыночной стоимости библиотеки ($).
   - Топ-1 любимая игра и Топ запускаемых игр.

3. **Интерактивный список игр**:
   - Поиск по названию игры в реальном времени.
   - Фильтры: "Все", "Сыгранные", "Не запущено".
   - Сортировка: по наигранному времени, по алфавиту, по недавним запускам.
   - Прямой переход на страницу игры в магазине Steam.

4. **Значки и достижения**:
   - Список значков с иконками, уровнем и заработанным опытом.

5. **Инвестиции времени & визитка геймера**:
   - Сравнение наигранных часов с реальной жизнью (сколько книг можно было прочесть, языков выучить, рабочих недель отработать).
   - Кнопка «Скопировать визитку геймера» для быстрой отправки друзьям в Discord/Telegram.

6. **Быстрый старт без API ключа**:
   - Встроенные демонстрационные профили (Гейб Ньюэлл, s1mple CS2, Коллекционер).
   - Возможность ввести свой Steam API ключ прямо в интерфейсе (сохраняется локально в браузере) либо в `.env`.

## 🛠️ Запуск проекта

### 1. Установка зависимостей (один раз)
```bash
npm run install:all
```

### 2. Запуск приложения

#### Режим разработки (сервер + Vite hot-reload):
```bash
npm run dev
```
- Frontend: `http://localhost:5173`
- Backend API: `http://localhost:5000`

#### Режим Production (единый сервер на Express):
```bash
npm run build
npm start
```
- Откройте браузер по адресу: `http://localhost:5000`

## 🔑 Настройка Steam Web API Key (по желанию)

Для поиска произвольных любых аккаунтов в реальном времени Steam требует бесплатный Web API ключ:

1. Перейдите на [https://steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) и войдите в свой аккаунт Steam.
2. В поле *Domain Name* введите любое имя (например `localhost`) и нажмите кнопку создания.
3. Скопируйте ключ и либо:
   - Вставьте его прямо в браузере, нажав кнопку **«Steam API Key»** в верхнем меню сайта;
   - Либо создайте файл `server/.env` со строкой:
     ```env
     STEAM_API_KEY=ваш_32_значный_ключ
     ```
