## Вариант 2: Полноценный бесплатный хостинг 24/7 (Render.com)

**Render.com** предоставляет бесплатный тариф для Node.js приложений с автоматическим HTTPS и постоянным адресом вида `https://steamstats-xxx.onrender.com`.

### Шаги для размещения на Render:

1. **Создайте репозиторий на GitHub:**
   - Зайдите на [github.com](https://github.com) и создайте новый репозиторий (например, `steamstats`).
   - Загрузите в него содержимое папки `d:\steamstats`.

2. **Подключите Render:**
   - Зарегистрируйтесь на [render.com](https://render.com) (можно войти через GitHub в один клик).
   - Нажмите синюю кнопку **«New +»** вверху справа и выберите **«Web Service»**.
   - Выберите ваш репозиторий `steamstats`.

3. **Настройки (заполняются автоматически):**
   - **Name:** `steamstats`
   - **Environment:** `Node`
   - **Build Command:** `npm run build`
   - **Start Command:** `npm start`
   - **Plan Type:** выберите **Free ($0/month)**.

4. Нажмите кнопку **«Deploy Web Service»**.

Через 1-2 минуты сайт скомпилируется и будет работать 24/7 по бесплатному постоянному адресу в интернете!
